What I’m exploring

Reliable software, useful AI, and the systems that connect them.

This page was generated with AI assistance for Project 1, using my supplied resume and project materials. It describes possible directions connected to that experience.

01

Backend systems that hold up in practice

My work at SPDB involved transaction services, data migration, and production incidents. That experience makes reliability a natural area to keep exploring: how services handle failures, how data stays correct, and how to make changes safely.

A question to explore: how can a system stay understandable as its scale and complexity grow?

Related experience: SPDB

02

The infrastructure behind AI

Model serving brings new constraints to familiar infrastructure: long startup times, limited GPU memory, and resources that cannot always be shared between replicas. My vLLM project is a place to investigate these constraints through small, reproducible experiments.

A question to explore: what should deployment and monitoring look like when a model needs minutes to become ready?

Related project: LLM Inference on Kubernetes

03

Software that interacts with the physical world

DroneRanger connects control logic with sensors, obstacles, and movement. It offers another view of dependable software: behavior needs clear limits, and simulation provides a way to investigate it before running on hardware.

A question to explore: how can simulation make autonomous behavior easier to test and explain?

Related project: DroneRanger
